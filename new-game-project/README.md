# Box Balance
#
# A compact 2D physics stacking puzzle built in Godot 4 using GDScript.
#
# Controls:
# - A / D or Left / Right: move the current box left and right.
# - Space: drop the current box.
# - R: restart the level.
# - Esc: pause or resume.
#
# Goal:
# - Build stable stacks to reach the target height for each level.
# - Survive the moving platform and wind stages.
# - Complete all five levels to win the game.
